# Bitcoin Cycle Map · 比特币周期地图

一个用于 TradingView 的 Pine Script v6 指标，将比特币历史周期高低点、减半日期、周期时间假设和指定区间最低价放在同一张价格图表上，方便学习、复盘和调整自己的周期观察框架。

适合希望在日线趋势与价格行为分析之外，增加长期时间参考的比特币交易学习者。

> 周期时间窗口是历史时长的类比，不是未来顶底的确认信号。历史标注是手动整理的数据，指标不会自动识别牛熊，也不会自动下单。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 历史周期标注 | 内置2011年以来的主要周期高点、低点，可添加或修改记录 |
| 减半日期标注 | 显示四次历史减半，以及可手动调整的下一次减半估计日期 |
| 周期时间推算 | 从假设顶部推算低点窗口，再推算下一高点窗口 |
| 独立低点锚点 | 可直接从指定低点日期推算下一高点，避免继续叠加预测低点的误差 |
| 区间最低价 | 统计指定日期至最新数据K线的最低价，标记价格与所在K线日期 |
| 阶段背景与表格 | 展示假设上涨、下跌阶段及对应日期 |
| 外观自定义 | 调整标签文字、方向、颜色、字号、线型、透明度与表格位置 |

各模块可以独立开关。隐藏时间推算不影响历史标注、减半或区间最低价功能。

## 快速开始

1. 打开本仓库的 [Bitcoin_Cycle_Map.pine](Bitcoin_Cycle_Map.pine)，复制完整代码。
2. 在 TradingView 打开 BTC/USD 或 BTC/USDT 图表。
3. 打开 Pine 编辑器，新建指标，将代码完整粘贴进去。
4. 保存并添加到图表。
5. 进入指标设置，调整日期、阶段天数和显示样式。

建议先使用**标准日线K线**。无需本地安装开发环境或额外依赖。若希望查看更早的历史标注，需要选用历史覆盖足够长的数据源；查看未来标记时，可向右移动图表。

## 设置说明

| 设置分组 | 可调整内容 |
| --- | --- |
| 01 显示 | 历史、减半、推算、最低价、表格、背景、竖线及窗口边界 |
| 02 时间模型 | 假设顶部、上涨和下跌天数、独立低点锚点、减半估计日期 |
| 03 区间最低价 | 统计起点、相同最低价取首次或末次、标签文字 |
| 04 标签与外观 | 高低点文字、标签方向、配色、字号、线型、排版高度及表格位置 |

### 标签文字与方向

- 将“历史低点文字”改为 `Bottom`，即可修改使用默认名称的低点标签。
- 开启“低点文字放在标注位置下方”，标签文字位于标注价格下方，箭头朝上。
- 高点和低点的方向分别设置，与颜色无关。
- 设置了专属文字的历史事件，不受统一名称设置影响。

### 预测标签的位置

“预测标签基准价格”默认是 `0`，表示使用最新收盘价作为排版基准；输入正数可固定排版高度。“预测标签分层间距%”用于减少文字重叠。

这些纵向位置仅用于显示，不代表未来目标价格。

## 时间模型如何计算

### 默认模式

```text
较早低点 = 假设顶部日期 + 下跌最短天数
参考低点 = 假设顶部日期 + 下跌参考天数
较晚低点 = 假设顶部日期 + 下跌最长天数

较早高点 = 较早低点 + 上涨最短天数
参考高点 = 参考低点 + 上涨参考天数
较晚高点 = 较晚低点 + 上涨最长天数
```

### 独立低点模式

开启“使用独立低点锚点推算下一高点”后，下一高点从你指定的低点日期计算：

```text
较早高点 = 独立低点日期 + 上涨最短天数
参考高点 = 独立低点日期 + 上涨参考天数
较晚高点 = 独立低点日期 + 上涨最长天数
```

原先从顶部推算的低点窗口仍然保留，以便比较两种假设。输入的独立低点必须晚于假设顶部。

### 默认参数的来源

| 阶段 | 使用的历史持续天数 | 最短 / 参考 / 最长 |
| --- | --- | --- |
| 高点至下一低点 | 410、363、376天 | 363 / 383 / 410天 |
| 低点至下一高点 | 1068、1061天 | 1061 / 1065 / 1068天 |

下跌参考值为三个样本的平均值；上涨参考值为两个样本的平均值取整。较早的上涨周期未纳入默认上涨参数，这是模型的人为取样选择。

**这些参数是手动设定的默认值。修改历史事件列表，不会自动重新计算参数；窗口两端也不构成统计置信区间。**

脚本统一使用 UTC 时间与自然日。下一次减半日期同样是手动估计，不联网更新，实际减半由对应区块高度触发。

## 添加或修改历史标注

在脚本 **C. 历史数据编辑区** 中，每行表示一个独立事件：

```pine
    // 日期、标签价格位置、事件类型、专属文字。
    array.push(events, CycleEvent.new(f_ts(2022, 11, 21), 15500.0, "bottom", "2022年熊市底部"))
```

修改已有记录即可调整该事件；添加新事件时，在 `if barstate.isfirst` 内添加一行并保持缩进，避免重复添加同一事件。

| 字段 | 说明 |
| --- | --- |
| `f_ts(年, 月, 日)` | UTC零点的事件日期 |
| `price` | 标签在图表中的价格位置，必须大于0 |
| `kind` | `"top"`、`"bottom"` 或 `"halving"` |
| `customTitle` | 专属文字；留空 `""` 时使用设置中的统一名称 |

每条事件独立保存类型，调整顺序不会把高点误识别为低点。日期会自动追加到标签；专属文字可使用 `\n` 换行。目前最多支持180条历史事件，为其他标注预留对象数量。

历史价格只是近似标签坐标，不参与时间推算。修改历史顶部记录也不会自动修改设置中的“假设顶部日期”。

## 区间最低价的统计范围

此功能逐根比较当前图表的 `low`，统计开盘时间不早于指定起点的K线，并包含尚未收盘的最新K线。新低出现时，标签会更新；相同低价默认保留第一次，可改为最后一次。

使用时需要了解以下边界：

- **数据源：**最低价来自当前交易所和交易对，不同数据源可能得到不同结果。
- **图表周期：**日线只能定位到天；周线中跨越起点的那根K线会被排除，可能漏掉起点之后的盘中低价。
- **起点时间：**建议使用与日线开盘对齐的起点；UTC零点适合常见加密货币日线数据。
- **历史覆盖：**加载历史晚于起点时，脚本会提示覆盖不足；此时结果只代表已加载范围。
- **图表类型：**建议使用标准K线，Heikin Ashi等合成K线的数值不能当作真实交易报价。
- **历史回放：**最低价统计至回放进度，历史事件也按数据进度过滤；但手动顶底记录仍含事后信息，不适合用来证明当时能够提前识别顶底。

## 精简标注模式

默认开启“04 标签与外观 → 精简预测与最低价标签”：

- `B`：低点时间参考；`T`：高点时间参考；`H`：下一次减半的手动估计日期。
- 预测文字为无底色的小字号，完整解释与日期放在鼠标悬停提示中。
- 窗口边界仅保留淡虚线，不显示大标签；窗口日期和B/T参考日期可在表格查看。
- 区间最低价默认显示 `Low`，价格、日期与历史覆盖提示放在悬停提示和表格中。
- “精简Low文字下移%”仅调整文字高度，不改变统计结果；设为0使文字回到最低价坐标。
- 历史高低点标签保持原样。关闭精简模式可恢复预测及最低价的完整标签。

已有指标实例若仍保留旧的“最低价标签文字”，请手动改为 `Low`。修改后需将完整源码更新到TradingView。此修改尚未在TradingView实际编译和视觉验证。
